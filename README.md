# RISM Digital Site

This is the source for the website at https://rism.digital.

## How to edit

There are two branches on this repository, 'staging' and 'master'.
Any edits you make should be made to staging first so that they
can be tested. The corresponding website is "https://stage.rism.digital".
(You will need a password to access this site; please ask and we can
give you it.)

When you are confident in your changes, you should file a "Pull Request"
for merging staging into master, and assign someone else to review it.
When they accept your proposed changes, they will merge your pull request
and it will be automatically deployed to the live site at "https://rism.digital".
