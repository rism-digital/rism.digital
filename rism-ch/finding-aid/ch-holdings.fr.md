# Liste alphabétique de toutes les bibliothèques et archives possédant des sources musicales

Bibliographie : RISM OPAC et volumes imprimés, enquête RISM 1990, Handbuch der historischen Buchbestände in der Schweiz, enquête Fonoteca nazionale svizzera 2000, Swisscovery (mise à jour : juillet 2018). 

Brève définition des catégories utilisées dans les descriptions sommaires :
Éditions musicales imprimées = titres des séries RISM A/I, B/I et B/II ; Manuscrits musicaux = sources des séries RISM A/II ; Sources de théorie musicale = sources des séries RISM B/VI ; Chants religieux = sources des séries RISM B/VIII ; Collections personnelles = principalement des manuscrits du XXe siècle.
